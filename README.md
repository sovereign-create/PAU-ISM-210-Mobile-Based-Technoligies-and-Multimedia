# PAU-ISM-210-Mobile-Based-Technologies-and-Multimedia

# Emmanuel Dakok first launched backend API
This is a backend API for handling login and form submissions. 
Built with Node.js, Express, and MongoDB then hosted with Render.

## Installation
1. Copy repo link
https://github.com/sovereign-create/PAU-ISM-210-Mobile-Based-Technoligies-and-Multimedia.git

2. Install dependencies
npm install

3. Start the server
npm start

## Usage
- POST /api/submit-form/login
- Send JSON data in request body

## Live Link
https://emmanuel-dakoks-backend.onrender.com

## Tech Stack
- Node.js
- Express
- MongoDB
- Mongoose
